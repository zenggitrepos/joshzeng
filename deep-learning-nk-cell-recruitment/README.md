

# Deep Learning for NK-cell Recruitment Prediction

## Overview

This project is to create a feedforward deep-learning workflow for predicting NK-cell recruitment from microbial product–associated features.


## Workflow

1. Load microbial product and immune-response feature data
2. Preprocess and structure input features for model training
3. Train a feedforward neural network
4. Evaluate model performance
5. Interpret prediction results in the context of NK-cell recruitment

## Tools

- Python
- PyTorch / deep-learning framework
- pandas
- NumPy
- scikit-learn
- Jupyter Notebook
