# Convert h5ad to Seurat Object


## Workflow

1. Load an `.h5ad` single-cell dataset
2. Inspect expression matrix, metadata, and feature annotations
3. Convert AnnData structure into a Seurat-compatible object
4. Preserve cell-level metadata and gene-level information
5. Save the converted object for downstream Seurat analysis

## Tools

- R
- Seurat
- SeuratDisk
- AnnData / h5ad format
- Jupyter Notebook
