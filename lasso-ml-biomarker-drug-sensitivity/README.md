# LASSO Biomarker Modeling for Drug Sensitivity

## Overview

This project demonstrates a machine-learning workflow for identifying predictive biomarkers of drug sensitivity using high-dimensional cancer cell-line data.

The analysis applies LASSO regression to select molecular features associated with response to Dolastatin-10, a microtubule-targeting anticancer compound. 

## Workflow

1. Load drug-sensitivity and molecular feature data from cancer cell lines
2. Preprocess and align response variables with predictor features
3. Apply LASSO regression for feature selection
4. Identify candidate biomarkers associated with drug sensitivity
5. Evaluate model performance and selected predictors
6. Interpret results in the context of cancer pharmacogenomics

## Tools

- Jupyter Notebook
- LASSO regression
- glmnet / machine-learning packages
- pandas / data-frame processing
