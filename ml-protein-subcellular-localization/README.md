# Machine Learning for Protein Subcellular Localization

## Overview


This project focuses on a machine-learning workflow for predicting protein subcellular localization using protein sequence-derived features. The analysis applies Support Vector Machine classifiers, including SVC and NuSVC, with comparison to Random Forest models, to classify the likely cellular compartments where proteins are localized.

## Workflow

1. Load protein sequence and localization data
2. Prepare and clean the dataset
3. Generate or process sequence-derived features
4. Train machine-learning models for localization prediction
5. Evaluate model performance using classification metrics
6. Interpret important features and prediction results
