

## Deep Learning for Antibody–Antigen Binding Affinity Prediction

## Overview

This project is a deep-learning workflow for predicting antibody–antigen binding affinity from protein sequence-derived features. The workflow combines protein sequence representation, feature generation, model training, and evaluation to support computational analysis of antibody–antigen interactions.


## Workflow

1. Generate protein sequence features for antibodies and antigens
2. Extract sequence embeddings using a protein language model
3. Process physicochemical amino acid features using AAindex/PCA
4. Train a deep-learning model for antibody–antigen binding prediction
5. Evaluate model performance on binding-affinity prediction tasks
6. Use model outputs to support antibody screening and prioritization
