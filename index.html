LLM Biomarker Assistant

A retrieval-augmented generation program that retrieves biomedical evidence and produces structured, citation-grounded translational research summaries.

Workflow

  • Biomedical evidence ingestion from JSONL
  • Live PubMed and ClinicalTrials.gov collectors
  • Local sentence-transformer embeddings and persistent Chroma storage
  • Semantic retrieval with an evidence table
  • Hosted free-LLM generation through an OpenAI-compatible API
  • Pydantic schema validation with automatic JSON repair retries
  • Citation allow-list guardrails
  • Contradictory-evidence and confidence fields
  • Streamlit user interface

Skills Demonstrated

LLMs, RAG, biomedical literature retrieval, PubMed, ClinicalTrials.gov, vector search, Python, Streamlit, translational biomarker discovery, and oncology evidence synthesis.
