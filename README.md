# Joshua (Xuehuo) Zeng, PhD  

## Computational Biology | Bioinformatics | Translational Data Science

This repository highlights selected projects in computational biology, bioinformatics, machine learning, single-cell/spatial analysis, biomarker discovery, LLM/RAG applications, and AI-enabled drug discovery.

## Featured Projects

### Biomarker Discovery & Machine Learning

- [LASSO Biomarker Modeling for Drug Sensitivity](lasso-ml-biomarker-drug-sensitivity)  
  LASSO-based biomarker discovery for cancer drug sensitivity.

- [Machine Learning for Drug Sensitivity Prediction](machine-learning-drug-sensitivity-prediction)  
  Supervised machine learning and Elastic Net modeling for drug-response prediction.

- [Machine Learning for Immunotherapy Response Prediction](ml-immunotherapy-response-prediction)  
  QLattice and LASSO regression for immunotherapy response prediction and patient stratification.

- [Machine Learning Feature Selection](machine-learning-feature-selection)  
  Feature-selection workflows for high-dimensional biological data.

### Single-cell, Spatial & Epigenomics

- [Single-cell RNA-seq Analysis of Melanoma](single-cell-rnaseq-melanoma)  
  Seurat-based melanoma single-cell RNA-seq analysis.

- [Single-cell RNA-seq Analysis of Colorectal Cancer](single-cell-rnaseq-colorectal-cancer)  
  Single-cell RNA-seq analysis of colorectal cancer tumor microenvironment.

- [Single-cell RNA-seq Analysis of Head and Neck Cancer](single-cell-rnaseq-head-neck-cancer)  
  Single-cell analysis of tumor and immune-cell populations.

- [Spatial Immune-cell LASSO Cox Survival Analysis](spatial-immune-lasso-cox-survival-analysis)

- [ATAC-seq Analysis Pipeline](ATAC_seq)  
  ATAC-seq QC, alignment, peak calling, FRiP calculation, IDR analysis, and visualization.

### AI / LLM / Deep Learning / Protein Bioinformatics
